# Electrical Machines Education

Interactive browser-based simulator for learning AC electrical machines — voltage transformation, reactive power, waveforms, and power calculations.

## 🚀 Quick Start

```bash
cd web
npm install
npm run dev
```

## 📊 Visualizations

1. **Power Triangle** - Vector diagram showing P, Q, S relationships
2. **Voltage & Current Waveforms** - Time-domain AC signals
3. **Power Calculation** - Instantaneous power with energy flow shading
